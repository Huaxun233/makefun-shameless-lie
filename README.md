# the-most-shameless-lie

[![make.fun](https://make.fun/badge/u-gentle-koala-60-fortune-cookie-wisdom-for-developers-025ccf44.svg)](https://make.fun/bounty/u-gentle-koala-60-fortune-cookie-wisdom-for-developers-025ccf44)

Entry for make.fun's The Most Shameless Lie bounty.

## The lie

```text
I read the terms and conditions.
```

## Run it

```sh
node main.ts
```

## Why this lie

It is the only lie everyone tells and nobody believes, including the listener —
they told the same one this morning. Short, five words, and instantly
verifiable as false, which is exactly what makes it shameless.
